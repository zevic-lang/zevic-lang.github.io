C のコードをそのまま使える、
小さなネイティブ言語。

C との境目はありません。ヘッダを import C するだけで、C のライブラリがそのまま使えます。Zevic は、ソースを LLVM IR に変換し、clang で機械語にします。型は必ず書き、失敗は Result で返し、メモリは GC が管理します。コンパイラは Zevic 自身で書かれています。

はじめてみる インストール Zevic とは 
module Main

import Zevic.Console

fn FizzBuzz(n: I32) -> String {
    if (n % 15 == 0) {
        "FizzBuzz"
    } else if (n % 3 == 0) {
        "Fizz"
    } else if (n % 5 == 0) {
        "Buzz"
    } else {
        "${n}"
    }
}

fn Main() {
    for (i in 1..=20) {
        Console.Println(FizzBuzz(i))
    }
}

コンパイルして実行

zevic fizzbuzz.zev -o fizzbuzz
./fizzbuzz

if や match は値を返す式で、最後の式が関数の戻り値です。例外も null もありません。続きははじめての Zevicで。

特長

  • C との境目がないimport C "sqlite3.h" の 1 行で、C のヘッダの関数・構造体・定数が使えます。構造体の値渡しも、C のコードなしです。詳しく
  • OS も書ける--freestanding でランタイムも GC も使わずにビルドし、カーネルを書けます。詳しく
  • セルフホストコンパイラ zevic1 は Zevic で書かれ、自分自身を同じ LLVM IR にビルドできます（make bootstrap）。
  • 失敗を型で表すOption と Result、? 演算子。例外はなく、null もありません。
  • 型の表現力struct / class / enum / interface、ジェネリクス、クロージャ、共用体型 A | B。
  • 並行処理async / await、チャネル、OS スレッド（Thread.Spawn）、多倍長整数 BigInt。
  • 標準ライブラリFs Json Net Regex Csv Toml DateTime Zip Cli など 30 以上のモジュール。
  • 道具パッケージ・ビルドの zevpm、整形の zevfmt、test ブロックによるテスト。
  • GC 付きBoehm GC を同梱。メモリ管理を意識せずに書けます。
