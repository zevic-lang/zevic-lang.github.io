v0.5.0 は、1.0 の前に直しておきたいことをまとめて入れたリリースです。**破壊的変更を含みます。**

いちばん大きいのは、フィールドの書き方です。クラスと構造体のフィールドを、変数と同じ `let` と `mut` で宣言します。

```zevic
class Counter {
    let name: String           // Init の中でだけ代入できる
    mut count: I64 = 0         // いつでも変えられる
    static let Start: I64 = 100
}
```

今までの `name: Type` はエラーになりました。`mut name: Type` と書き直せば、同じ意味になります。

新しい機能もあります。`unsafe { }` ブロックと `unsafe fn` の中では、`Zevic.Unsafe` の `Alloc` と `Free` で、GC を使わない手動のメモリが使えます。GC が管理する参照は置けない決まりです。使い方は[解説ページ](/unsafe/)にあります。`Printf` と `Text.Format` では、`%{I32}` や `%.2{F64}` のように型を書けます。

ほかに、将来のために `union`、`volatile`、`pub`、`try` が予約語になりました。標準ライブラリでは `Env.OS()` が `Env.Os()` に、`DateTime.Nano()` が `DateTime.Nanosecond()` になり、`Regex` などの内部の型は非公開になりました。

詳しくは[リリース](/releases/)をご覧ください。
