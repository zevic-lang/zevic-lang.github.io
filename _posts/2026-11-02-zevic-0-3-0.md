v0.3.0 で、パッケージとビルドの道具 **zevpm** が入りました。

```sh
zevpm new myapp
cd myapp
zevpm run
zevpm test
```

プロジェクトは `zevic.toml` で設定します。依存は git（タグ、ブランチ、コミット）か手元のパスで指定でき、実際のコミットは `zevic.lock` に固定されます。ライブラリ（`kind = "lib"`）は静的ライブラリと C ヘッダーとしてビルドできます。

テストは `test "名前" { ... }` ブロックか `_test.zev` ファイルに書き、`zevpm test` で動かします。`Zevic.Test` には `Equal` や `Panics` などがあり、テスト内の Panic はそのテストだけを失敗にします。

標準ライブラリには `Math`、`Env`、`Text`、`Time`、`Fs`、`Process` と標準入力が加わりました。`examples/apps/wordcount` は、テストつきの zevpm パッケージの例です。
