---
title: "Zevic 0.0.3: struct・class・enum と Option・Result"
---
v0.0.3 で、データを扱うための機能が揃いました。

- `struct`（値型）、`class`（参照型）、`enum`（データを持てる）
- `match`。ガード、範囲、入れ子のパターンに対応し、網羅していないとコンパイルエラーになります
- `Option` と `Result`、そして `?` 演算子。どちらも言語の特別扱いではなく、標準ライブラリが `enum` で定義しています
- `Array<T>` も Zevic 自身で書かれています
- ジェネリクス（型ごとに関数を生成します）とタプル

例外と null を持たない設計は、この版で形になりました。失敗は戻り値で、バグは `Panic` で扱います。

```zevic
fn Half(n: I32) -> Result<I32, Error> {
    if (n % 2 != 0) {
        return Err(Error.New(ErrorKind.Invalid, "${n} is odd"))
    }
    Ok(n / 2)
}

fn Quarter(n: I32) -> Result<I32, Error> {
    let h: I32 = Half(n)?
    Half(h)
}
```
