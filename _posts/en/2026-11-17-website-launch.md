The official Zevic website is open. It has an overview of the language, installation instructions, tutorials, the release record and the developers.

- New to programming? Start with the [tutorial](/en/start/)
- Already using another language? Read [Coming from other languages](/en/from-other-languages/)
- The latest release is [v0.4.5](/en/releases/#v0.4.5)

The source of the site is in [zevic-lang.github.io](https://github.com/zevic-lang/zevic-lang.github.io). If something is wrong or hard to follow, please tell us in an issue.
