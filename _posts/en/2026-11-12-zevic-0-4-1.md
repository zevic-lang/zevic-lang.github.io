v0.4.1 widens the standard library a great deal.

**Language and prelude**

- `Text.Format("%5d|%-8s|%.2f", ...)`: C-style formatting that returns a `String`. As with `Printf`, the format is a string literal, and the compiler checks the count and types
- `StringBuilder`
- Many methods on `Iterable`, `Array`, `Map` and `Set` (`Take`, `Skip`, `Zip`, `GroupBy`, `Sorted`, `Union` and more)
- UTF-8 aware methods on `Text`

**New modules**

`Chars`, `Path`, `Bytes`, `Encoding`, `Digest` (SHA-256, HMAC and more), `DateTime`, `Log`, `Cli`, `Regex`, `Csv`, `Toml`, `Net` (TCP and UDP), and `Deflate`, `Zlib`, `Gzip`, `Zip` and `Tar`.

**Layout and examples**

The C implementation (zevic0) moved to [zevic-c](https://github.com/zevic-lang/zevic-c). This repository now builds with clang alone. `examples/interop/` has examples of C++, Rust, Go and Python calling a Zevic library, and of Zevic calling Rust and C++.
