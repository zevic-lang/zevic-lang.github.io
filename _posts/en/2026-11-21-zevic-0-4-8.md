v0.4.8 lets you build for other systems.

Give a target, as in `zevic --target windows-x64 hello.zev -o hello.exe`, and you get an executable for another OS and CPU. `zevpm build --target linux-arm64` writes to `build/linux-arm64/`. The C headers and libraries that are needed come from [Zig](https://ziglang.org/). `install.sh --with-zig` (`install.ps1 -WithZig` on Windows, or "Install Zig" in the setup) installs it after checking it. It is off by default.

The releases now include Linux arm64, macOS Intel and Windows on Arm.

There is also a [playground](/en/playground/). The compiler and the runtime are built for WebAssembly, so typing code and running it all happen in your browser, and nothing is sent to a server. It has limits, such as no files and no network, which are written on the page.

See the [releases](/en/releases/) for details.
