v0.3.1 is a full release.

- **zevfmt**: the code formatter. `zevfmt -w .` rewrites files and `zevfmt -check .` verifies them. It normalises indentation, spacing, blank lines, trailing commas and import order, and a test over the whole repository checks that it never changes the AST
- **Loop labels**: `outer@ for (...) { ... break@outer ... }`
- **async / await**: `async { ... }` and `await`, with `Zevic.Async` (`Task`, `Spawn`, `Channel`, `Mutex`)
- **HTTP**: `Get`, `Post` and `Send` in `Zevic.Http`, plus `Listen` / `Server.Serve` (no TLS yet)
- **Random**: SplitMix64, which returns the same numbers for the same seed on every platform
- **Json**: an RFC 8259 parser, plus `Stringify` and `Pretty`. Errors carry a line and a column

`zevpm` was rewritten in Zevic in this version: the first practical program written in the language.

We also fixed many macOS and Windows problems found by the first CI runs (sockets, the GC, path handling and others).
