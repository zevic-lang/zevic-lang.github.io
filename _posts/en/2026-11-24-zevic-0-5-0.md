v0.5.0 puts together what we wanted to fix before 1.0. **It has breaking changes.**

The biggest is how fields are written. Fields of a class or a struct are declared with `let` and `mut`, like variables.

```zevic
class Counter {
    let name: String           // can be set only in Init
    mut count: I64 = 0         // can be changed any time
    static let Start: I64 = 100
}
```

The old `name: Type` is an error now. Write `mut name: Type` and it means the same.

There are new features too. Inside an `unsafe { }` block or an `unsafe fn`, `Alloc` and `Free` of `Zevic.Unsafe` give you manual memory that the GC does not manage. It cannot hold references the GC manages. See the [guide](/en/unsafe/). In `Printf` and `Text.Format` you can write the type, as in `%{I32}` or `%.2{F64}`.

Also, `union`, `volatile`, `pub` and `try` are reserved for the future. In the standard library, `Env.OS()` is `Env.Os()` and `DateTime.Nano()` is `DateTime.Nanosecond()`, and the internal types of `Regex` and others are private.

See the [releases](/en/releases/) for the details.
