v0.3.0 brings **zevpm**, the package and build tool.

```sh
zevpm new myapp
cd myapp
zevpm run
zevpm test
```

A project is configured in `zevic.toml`. Dependencies are given as git (tag, branch or commit) or as a local path, and the exact commits are pinned in `zevic.lock`. A library (`kind = "lib"`) builds as a static library with a C header.

Tests are written in `test "name" { ... }` blocks or in `_test.zev` files, and run with `zevpm test`. `Zevic.Test` has `Equal`, `Panics` and more, and a Panic inside a test fails only that test.

The standard library gained `Math`, `Env`, `Text`, `Time`, `Fs`, `Process` and standard input. `examples/apps/wordcount` is an example of a zevpm package with tests.
