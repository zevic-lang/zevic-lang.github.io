---
title: "Zevic 0.3.1: zevfmt・async・HTTP"
---
v0.3.1 は盛りだくさんの版です。

- **zevfmt**: コードの整形ツール。`zevfmt -w .` で書き換え、`zevfmt -check .` で検査します。インデント、空白、空行、末尾のカンマ、import の順序を整え、AST を変えないことをリポジトリ全体でテストしています
- **ループラベル**: `outer@ for (...) { ... break@outer ... }`
- **async / await**: `async { ... }` と `await`、`Zevic.Async`（`Task`、`Spawn`、`Channel`、`Mutex`）
- **HTTP**: `Zevic.Http` の `Get`、`Post`、`Send` と、`Listen` / `Server.Serve`（TLS はまだありません）
- **Random**: 同じシードなら、どの環境でも同じ乱数を返す SplitMix64
- **Json**: RFC 8259 のパーサーと、`Stringify` / `Pretty`。エラーには行と列が付きます

`zevpm` は、この版で Zevic 自身で書き直されました。言語で作った最初の実用的なプログラムです。

また、初めての CI で見つかった macOS と Windows の不具合（ソケット、GC、パスの扱いなど）を多数修正しました。
