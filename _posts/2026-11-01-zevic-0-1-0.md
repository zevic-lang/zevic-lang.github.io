v0.1.0 は、名前のとおり「C をそのまま使える」ための版です。

C の関数は `extern "C"` で宣言して呼び、Zevic の関数は `export "C"` で C に公開できます。`--emit-header` で C のヘッダーも作れます。`.c`、`.cpp`、`.o`、`.a` は一緒にビルドでき、`-I` `-D` `-L` `-l` はそのままコンパイラ／リンカーに渡されます。

```zevic
extern "C" {
    fn puts(s: CString) -> CInt
}

fn Main() {
    let r: CInt = puts("hello".ToC())
}
```

C の型（`CInt` `CString` `CLong` ほか）と Zevic の型の間に暗黙の変換はなく、`x.ToCInt()` や `String.FromC(p)` のように明示します。

言語側では `interface` が入りました。必須メソッド、デフォルトメソッド、interface の継承、動的な呼び出しに対応し、ジェネリクスの制約（`<T: Comparable + Hashable>`）も書けます。`Map<K, V>`（挿入順）と `Set<T>` も、Zevic 自身で書かれた標準ライブラリとして加わりました。
