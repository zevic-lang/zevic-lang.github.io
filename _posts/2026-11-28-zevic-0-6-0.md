v0.6.0 は、「**C との境目がない**」ことを目指した、大きなリリースです。

C のライブラリは、世の中でいちばん多くの仕事を済ませています。言語が使われるには、そのライブラリを、手間なく使えなければなりません。今までの Zevic でも `extern "C"` で C の関数は呼べましたが、宣言を 1 つずつ手で書く必要があり、構造体を値で渡す関数には、C で書いた薄い橋渡し（シム）が要りました。

0.6.0 では、その手作業をなくしました。

## import C

```zevic
import C "sqlite3.h" as Sq strip "sqlite3_", "SQLITE_"

fn Main() {
    let v: CString = Sq.Libversion()
}
```

この 1 行で、clang がヘッダを読み、関数・構造体・`enum`・`#define` の定数が、そのまま使えるようになります。実際に [sqlite パッケージ](https://github.com/zevic-lang/sqlite)は、64 行あった C のシムをやめて、`import C "sqlite3.h"` だけで動くようになりました。生成されるモジュールを手で直したいときは、`zevic bind` でファイルに書き出せます。

## 構造体の値渡し

raylib のように `Vector2` や `Color` を値で受け渡す関数は、C の呼び出し規約が環境ごとに違い、手で合わせるのは間違えやすい部分です。Zevic は、これを C のコンパイラに任せます。コンパイラが、ポインタで受け取る小さな C の関数（シム）を自分で書いてコンパイルし、使う側には、ふつうの値渡しの関数に見せます。

```zevic
let s: Rl.Vector2 = Rl.Vector2Add(a, b)
Rl.ClearBackground(color)
```

詳しくは、新しい[解説ページ「C と一緒に使う」](/c/)にまとめました。コールバックに `Null` を渡す方法や、`SQLITE_TRANSIENT` のように番号が意味を持つ関数ポインタを渡す `Unsafe.CallbackAt` も、そこにあります。

## OS を書く

`zevic --freestanding` は、ランタイムも GC も標準ライブラリもリンクせずにビルドします。カーネルやファームウェアのように、土台が何もない場所で動くコードを、Zevic で書くためのモードです。`.S` のアセンブラや `.c` を一緒に渡せて、リンカスクリプトと入口の名前も指定できます。`zevic.toml` に `[freestanding]` を書いて、`zevpm build` でビルドすることもできます。

[examples/hello-os](https://github.com/zevic-lang/zevic/tree/main/examples/hello-os) は、RISC-V の QEMU で「Hello, World!」と表示するだけのカーネルです。UART への書き込みには、新しい `Unsafe.At` と `WriteVolatile` を使っています。ランタイムが要るコード（`class`、`Array`、文字列の連結など）は、実行時に壊れるのではなく、コンパイルエラーになります。解説は[「OS を書く」](/os/)にあります。

## Http はパッケージへ（破壊的変更）

標準ライブラリから `Zevic.Http` がなくなりました。クライアントは [curl パッケージ](https://github.com/zevic-lang/curl)（libcurl を使い、HTTPS・リダイレクト・プロキシに対応）、サーバーは新しい [httpd パッケージ](https://github.com/zevic-lang/httpd)です。`Zevic.Net`（TCP と UDP）は標準ライブラリに残ります。

C のライブラリが `import C` で使えるようになった今は、ネットワークや圧縮のような「C に任せたほうがよいもの」は、標準ライブラリに抱え込まず、パッケージとして育てていく方針です。

## まだできないこと

- 可変長引数の関数（`printf` など）と、式のあるマクロは、まだ束縛できません
- コールバックと値渡しの構造体を同時に取る関数も、まだ束縛できません
- freestanding のライブラリ（`kind = "lib"`）は、まだ作れません

束縛できなかったものは、`zevic bind` が理由つきで一覧にします。詳しくは[リリース](/releases/)をご覧ください。
