---
title: "Zevic 0.2.0: クロージャと GC"
---
v0.2.0 では、ラムダとクロージャ、`defer`、ガベージコレクションが入りました。

```zevic
let double: fn(I32) -> I32 = (x: I32) => x * 2

mut total: I32 = 0
nums.Each((x: I32) => { total += x })
```

ラムダの外側の `mut` 変数は取り込めて、変更は外側にも見えます。取り込まれた変数は GC が管理します。

メモリは Boehm GC（`runtime/third_party/bgc`）に任せるようになりました。ランタイムと GC は初回のビルドで一度だけコンパイルされ、`~/.cache/zevic` に保存されるので、2 回目以降のビルドは速くなります。

C との連携も広がりました。名前付きの関数や何も取り込まないラムダは、`qsort` のようなコールバックとして C に渡せます。`Handle<T>` を使うと、C 側に Zevic のオブジェクトを数値として持たせられます。
