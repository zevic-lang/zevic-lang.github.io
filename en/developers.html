Take part

Zevic is still a small project. Bug reports, documentation fixes, improvements to the standard library and tools, new examples and published packages are all welcome.

  • How development works: CONTRIBUTING.md
  • Language changes are written as proposals
  • Report problems on GitHub Issues
  • The code is released under Apache-2.0
