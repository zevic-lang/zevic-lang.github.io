Zevic is a language under development. While it is 0.x, the language specification and the standard library API may change. Changes are recorded in each release and in the CHANGELOG.

Status

AreaStatus
CompilerSelf-hosted (zevic1). The C implementation is archived
LanguageTypes, struct / class / enum / interface, generics, closures, union types, defer, async / await, test blocks
C interopextern "C" / export "C", header generation, building C / C++ sources together
Standard libraryOver 30 modules. HTTP has no TLS yet
Toolszevpm (packages, builds, tests) and zevfmt (formatter)
PlatformsLinux (x64), macOS (arm64), Windows (x64). Termux: build from source
Known limitsDateTime supports only fixed UTC offsets as time zones. TOML dates and times stay as text. Regex flags apply to the whole pattern

The roadmap is in docs/plan.md, and design proposals are in docs/proposals.
