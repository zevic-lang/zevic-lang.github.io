Zevic は開発中の言語です。0.x の間は、言語仕様や標準ライブラリの API が変わることがあります。変更点は各リリースの記録と CHANGELOG にあります。

開発状況

領域状況
コンパイラセルフホスト済み（zevic1）。C 実装はアーカイブ済み
言語機能型、struct / class / enum / interface、ジェネリクス、クロージャ、共用体型、defer、async / await、test ブロック
C 連携extern "C" / export "C"、ヘッダーの生成、C / C++ のソースの同時ビルド
標準ライブラリ30 以上のモジュール。HTTP は TLS 未対応
ツールzevpm（パッケージ・ビルド・テスト）、zevfmt（整形）
対応 OSLinux（x64）、macOS（arm64）、Windows（x64）。Termux はソースからビルド
既知の制限DateTime のタイムゾーンは固定オフセットのみ。TOML の日時はテキストのまま。正規表現のフラグはパターン全体に効く

ロードマップは docs/plan.md、設計の提案は docs/proposals にあります。
